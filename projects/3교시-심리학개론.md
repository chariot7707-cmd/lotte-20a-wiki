# 3교시 심리학개론

## 현황 (한눈에)
- 한 줄 요약: 이선영 교수님 수업. 자아탐색 보고서(4~5매)를 각자 작성해 14주차까지 제출. 수시시험은 완료, 시험은 오픈북.
- 다음 마일스톤: 보고서 제출 — 14주차 = 2026-12-07 (제출 방법 확인 필요) → 기말고사 2026-12-14

## 수업 안내 (공지 요지)
- **담당**: [이선영](../members/이선영.md) 교수님 — 연락처는 공지 원문 참고 (개인 연락처는 [보안 규칙](../rules/보안.md)에 따라 위키에 적지 않음)
- **시간·장소**: 월요일 14:20 ~ 16:20, 무용학부관 404호 ([시간표](../knowhow/2026-2학기-시간표.md))
- **시험**: 오픈북
- **수시시험**: 완료
- **기말고사**: 15주차 = 2026-12-14 (2026-11-16 학우 확인)

## 과제 — 자아탐색 보고서
- **주제**: 심리적 발달과 성장을 통해 살펴본 자아탐색에 대한 보고서 작성
- **담을 내용**
  1. 나의 출생과 역할
  2. 나의 유년기
  3. 청소년기
  4. 성인기
  5. **(중요)** low point / high point / turning point
  6. 나의 가치관과 미래 비전
- **분량**: 4~5매 — 분량보다 내용의 진실성이 중요
- **유의사항**
  - AI로 작성하지 말 것 — 진정성과 자기표현이 평가의 핵심
  - 기말고사와 연계: 리포트를 써 본 사람만 기말고사 문제를 쓸 수 있게 출제한다고 함 (공지 원문에 "(?)" 표기 — 확인 필요)
- **제출기한**: 14주차 = 2026-12-07 — 기말고사가 12/14(월요일반 15주차)라는 학우 확인에 따라 월요일반 [학사일정](../knowhow/2026-2학기-학사일정.md)으로 환산한 날짜

## 확인 필요

- 기말고사 연계 방식의 정확한 내용
