# 보안 — 이 레포에 넣으면 안 되는 것

> 이 레포는 팀 전용(비공개) 저장소에 둔다. **"팀 내부 문서와 같은 보안 등급"** 이 기준선이며, 아래는 그보다 엄격한 금지 목록이다.
> 회사 보안 정책이 더 엄격하면 그쪽을 따른다.

## 절대 금지 (커밋 전 확인)

- 고객·사용자 개인정보 (이름·연락처·주소·주민등록번호 같은 식별번호·회원 ID 실값 등 — 가상이어도 형식이 실데이터와 같으면 금지)
- 계정·비밀번호·토큰·API 키 (발급 절차를 적는 건 OK, 값은 금지)
- 내부 IP·서버 주소·보안 설정 상세
- 거래처 계약 조건·단가·미공개 실적 수치 원문 (필요하면 "계약 조건은 ○○ 담당 문서 참고"처럼 위치만)
- 사내 결재·품의 문서 **원문 첨부** (요지 요약은 OK)
- **회의 녹음 전사(STT) 원문** — 요약 회의록만 (CLAUDE.md §0)
- 인사·평가·개인 신상 (연봉·이동·휴가 사유 등)
  - ℹ️ 경계: `members/`의 **담당 프로젝트·레포·직무** 같은 업무 정보는 OK. 평가·성향·신상·미확정 인사는 금지
  - ⚠️ **팀 밖 인물(타 팀·외부)은 더 엄격히** — 본인 모르게 등록되는 페이지이므로 협업에 필요한 최소 정보(소속·담당·연락 맥락)만. 인상·대응 태도 같은 서술 금지

## 판단이 애매하면

넣지 말고 팀장에게 확인한다. "일단 넣고 나중에 지우기"는 git 히스토리에 남으므로 **넣지 않는 것과 같지 않다.**

## 사고 시

이미 커밋·푸시된 민감 정보를 발견하면: 즉시 팀장 보고 → 히스토리 제거(BFG 등)는 개발자와 함께. 조용히 덮지 않는다.
