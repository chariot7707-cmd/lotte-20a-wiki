# 커밋·동기화 — 신경 쓸 필요 없음 (자동)

**이 레포는 git 명령을 몰라도 됩니다.** clone에 포함된 훅(`.claude/settings.json`)이 알아서 합니다:

- **세션을 열면** → 자동으로 최신을 받아온다 (`pull --rebase`)
- **Claude 응답이 끝날 때마다** → 변경분이 있으면 자동 커밋 + 푸시

즉, 문서를 만들고 세션을 쓰기만 하면 항상 원격 저장소(GitHub 등)에 올라가 있고, 항상 최신을 보고 있습니다.

## 뭔가 꼬였을 때 (드묾)

- 훅이 "⚠️ 푸시 실패" 메시지를 남기면 → **"위키 커밋해줘"** 한마디. Claude가 rebase 충돌을 풀고 푸시합니다.
  - 메시지가 "원격에 닿지 못함"이면 인터넷 연결이나 저장소 로그인을 확인합니다.
  - 마크다운 충돌은 대부분 양쪽 내용을 다 살리면 되므로 Claude가 거의 항상 성공합니다.
- 로컬 커밋은 푸시 실패와 무관하게 안전하게 남습니다 — 유실되지 않습니다.

## 혼자 쓰기 모드 (git이 없을 때)

git이 없는 컴퓨터에서는 훅이 아무것도 하지 않습니다. 위키 문서·질문·대시보드는 그대로 쓸 수 있고, 팀과의 동기화만 꺼져 있습니다.
세션을 열 때 "혼자 쓰기 모드" 안내가 한 줄 뜨는 것이 정상입니다.

## 동기화 켜기 — "위키 동기화 켜줘" (Claude 전용 지침)

사용자가 이 말을 하면 Claude가 순서대로 한다:

1. git이 쓸 수 있는지 확인한다 (`command -v git`, macOS에서 `/usr/bin/git`이면 `xcode-select -p`도). 없으면 설치 방법을 안내하고 멈춘다 — macOS `xcode-select --install`, Windows Git for Windows, Linux 배포판 패키지.
2. `git config user.name`·`user.email`이 비어 있으면 묻고 설정한다.
3. 이 폴더가 git 저장소가 아니면 `git init -b main` → 전체 커밋. (`.gitignore`가 있는지 먼저 확인)
4. 원격 주소를 묻는다. 팀 저장소가 아직 없으면 **비공개(private)** 로 만들라고 안내한다. `git remote add origin <주소>`.
5. `git push -u origin main`. 인증 오류면 로그인이 필요하다고 안내한다(GitHub이면 `gh auth login` 또는 브라우저 로그인 창).
6. 성공하면 "이제부터 자동으로 동기화됩니다"라고 알린다. 팀원은 그 저장소를 clone해서 쓰면 된다.

## 수동으로 하고 싶은 사람만

```bash
git pull --rebase && git add -A && git commit -m "docs: 요약" && git push
```

## 왜 `git add -A`를 허용하나

이 레포에는 위키 문서만 있고, 각자 자기 클론에서만 작업하므로 남의 미완성 변경을 쓸어 담을 일이 없습니다.
(단, 그래서 **보안 규칙이 더 중요합니다** — 실수로 폴더에 넣은 파일도 자동으로 올라갑니다. [보안.md](보안.md) 필독.)
